## 🔍 01 — Port Scanner

A simple Python TCP port scanner that checks a range of ports on a target IP address.

### Features

- Scan a custom port range
- Detect open TCP ports
- Configurable connection timeout
- Simple command-line interface
- Displays a final scan summary

### Technologies

- Python
- Socket Programming
- TCP/IP

### Usage

Run:

```bash
python port_scanner.py
